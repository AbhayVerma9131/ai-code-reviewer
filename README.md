# AI Code Reviewer

## 💡 Problem
Developers often lack quick feedback on code quality and improvements.

## 🚀 Solution
An AI-powered system that analyzes code, detects issues, and suggests improvements.

## 🔥 Features
- Code analysis
- Issue detection
- Improvement suggestions

## ⚙️ Tech Stack
Python, Streamlit

## 🚀 Future Scope
- Add LLM-based explanations
- Multi-language support
- Complexity analysis
